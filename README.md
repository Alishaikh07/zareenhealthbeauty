# Zareen Health Care

## Overview

Zareen Health Care is a comprehensive healthcare service provider specializing in dental, hair, skin, and slimming treatments. Our mission is to deliver high-quality and affordable healthcare services to our clients, ensuring their well-being and satisfaction.

## Features

1. **Dental Care**: Comprehensive dental services including cleaning, fillings, braces, implants, and more.
2. **Hair Treatments**: Advanced hair care solutions such as hair transplant, laser treatments, and hair loss prevention.
3. **Skin Care**: A wide range of skincare treatments for a radiant and healthy complexion.
4. **Slimming Treatments**: Non-invasive slimming solutions and personalized weight management programs.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, Angular
- **Backend**: Django, Python
- **Database**: Firebase, Firestore
- **Design Frameworks**: Bootstrap
- **API Integrations**: ChatGPT API for chatbot functionality

## Key Functionalities

- **Responsive Design**: Ensures seamless access across devices.
- **Appointment Booking**: Allows users to schedule appointments conveniently.
- **Chatbot Integration**: AI-powered chatbot for instant assistance.
- **Image Gallery**: Sliding functionality with click-to-view details.
- **Data Analytics**: Tools for analyzing customer engagement and optimizing services.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/username/zareen-health-care.git
   ```
2. Navigate to the project directory:
   ```bash
   cd zareen-health-care
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   ng serve
   ```
5. Open your browser and go to `http://localhost:4200`.
